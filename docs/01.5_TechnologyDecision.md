# Technology Decision Record

> This document records every major technology decision made during the development of ExamCore.

---

# Purpose

The purpose of this document is to explain:

- Why a technology is selected
- Why alternatives are not selected
- Cost implications
- Future migration path
- Risks
- Upgrade strategy

---

# Architecture Principle

ExamCore follows:

- Zero Cost First
- Open Source First
- Documentation First
- AI Friendly Development
- Modular Architecture
- Enterprise Ready

# Decision 001 — Next.js

## Selected

Next.js App Router

### Why

- Modern React framework
- Excellent documentation
- Strong community
- Server Components
- Route Handlers
- Excellent Vercel integration

### Alternatives

- React + Vite
- Remix
- Nuxt

### Cost

🟢 Free

# Decision 005 — Supabase

## Why

- PostgreSQL
- Authentication
- Storage
- Row Level Security
- Free Tier
- Excellent TypeScript support

Alternatives

- Firebase
- Appwrite
- PocketBase

Decision

Supabase provides the best balance between simplicity and scalability.

# Decision 009 — Zero Cost First

Requirement

Every selected technology must have a usable free tier.

Paid services may only be adopted when justified by measurable growth.
